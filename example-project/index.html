Проєкт на GDevelop: Арканоїд 🎮

Огляд проєкту 📜

Цей проєкт демонструє можливості платформи GDevelop для створення 2D-ігор. У грі гравець керує платформою, яка відбиває м'яч, щоб знищити всі блоки на екрані.

Мета проєкту:

Створити класичну гру типу арканоїд з використанням візуального програмування в GDevelop.

Технічна реалізація ⚙️

Використані технології:

  • GDevelop для створення гри
  • Візуальне програмування подій
  • Фізика та відскок м'яча
  • Система рівнів та блоків
